## Minimal isolated example once implementation exists

Start with D01's running branch and D02 missing-Broker neighbor: use isolated fake sources/clock/owner/store and ordered effect observations, no real runtime/Keychain/network/telemetry. Supply a complete independently valid Policy read and separate admission/claim, exact generation and Broker result. A hypothetical fake's successful assertions qualify only that fixture path, never live counterparts or cross-crash durability. Implemented method and test-runner names are pending; there is no command to copy from this draft.

Expand to all C01–C47 with the exact unsupported/unknown/stale/correlation variants, not just these examples. An implementation that rejects every request must fail the valid controls. Intentional interface asymmetry matters: running Route works without Launcher, stopped does not; optional observations under explicit not_required policy differ from missing required clearance. Do not require invented symmetry.

## Check the checker before using its acceptance

For an eventual executable gate, establish a bounded known violation: in an isolated fixture let unknown-liveness Route wrongly launch while preserving all other valid inputs. Its D01 invariant must fail specifically on the forbidden launch, paired with the valid running/stopped controls. Then remove the violation and rerun. A plant that never applies, fails setup, times out or produces an unrelated error does not establish detection. Parser/output-budget gates need their own applicable known-invalid neighbor. No controls have been executed here; no reusable harness is included or authorized by this preparation.

After execution is separately admitted, run every selected lane despite an earlier red and report PASS/FAIL/UNRUN separately, with commands/versions/inputs/exit codes and retained post-failure state. Do not convert blocked compile/setup/unknown sources into product PASS. Real integration needs fresh counterpart admission, owner evidence/custody, durable restart/reconciliation checks and independent exact-candidate review; a fake and adapter agreeing is not independent ground truth.
